# 業種別デモ（セミナー用）

AIに日本語で頼んで作った、業種別の業務ツールのデモです。`index.html` が入口です。
表示しているデータはすべて架空のサンプルです。

| フォルダ | 業種 | デモ |
|---|---|---|
| `ec-inventory/` | 物販・EC・製造 | 在庫・発注アラート |
| `school-tuition/` | 教室・スクール・塾 | 月謝・振替かんたん帳 |
| `clinic-followup/` | 治療院 | 再来院フォロー帳 |
| `housing-estimate/` | 住宅・建築・不動産 | 見積・追客ボード |
| `btob-billing/` | コンサル・士業・BtoB | 案件・請求ボード |
| `healing-karte/` | 癒し・セラピー・占い | お客様カルテ＆フォロー |

## 使い方（Windows / Mac / スマホ 共通）

- **URLで受け取った場合**: ブラウザで開くだけです。インストールは不要です。
- **ファイルで受け取った場合**: 各フォルダの `index.html` をダブルクリックすると、ブラウザで開きます。
  - Windows: Microsoft Edge / Google Chrome
  - Mac: Safari / Google Chrome

## 動作要件

- Windows 10 以降 / 最新の macOS / iOS・Android の最近のブラウザ
- インターネット接続は、ページを開くときだけ必要です（ファイルで開く場合は不要）

## データの扱い

入力した内容は、お使いの端末のブラウザの中だけに保存されます。外部には送信されません。
連絡文などの文面は、決まった文面に名前や日付を当てはめて作っています（AIの利用料はかかりません）。
